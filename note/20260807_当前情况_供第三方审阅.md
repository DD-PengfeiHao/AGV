## 0. 一句话现状

我们在做一套 **NUC 上的 ROS2 Humble 送货系统**：开发模式用仿真（Gazebo soft + smap 地图）；Demo 实车模式用 **仙工 Robokit TCP** 控车；工业相机（Basler）走 **Xavier NX 上的 ROS2**，不是 RealSense，也不是正式 HTTP 主路径。  
**真车尚未在当前网络联通**；Robokit 协议用本地 Mock 冒烟通过；**Docker 守护进程当前不可用**，整机仿真容器未能在本会话内再次拉起验证。

## 2. 架构分层（避免审阅者混淆）

系统里其实有 **三套「导航相关」叙事**，不要混成一件事：

| 层 | 技术 | 本项目用法 |
|----|------|------------|
| A. **Roboshop** | Ubuntu/Windows 上位机 GUI | 人用；不进我们 ROS 图 |
| B. **Robokit TCP API** | 车端 `19204–19207`，二进制头 + JSON | **Demo 实车主通路**（Dashboard 直连 `RobokitClient`） |
| C. **ROS2 Nav2** | `bt_navigator` 等（同事截图在讲这个） | **本 Demo 车不用**；同事材料是概念/别的栈，不是当前契约 |

另有：

| 层 | 技术 | 本项目用法 |
|----|------|------------|
| D. **开发仿真 AGV** | `agv_gazebo_nav` + smap | Web「开发环境」；不走 Robokit |
| E. **工业相机** | Xavier ROS2 Humble + Basler/Aravis | `cam_front`；契约 docs/25 |
| F. **人脸** | 独立 Jetson / stub | docs/18；与相机契约分离 |

**重要实现细节（易踩坑）**：

- soft boot（`boot_gazebo_lite.sh`）起的是 **Gazebo 代理导航 + dashboard**，**默认不起** `agv_bridge_node`。
- Demo 模式：`dashboard_node` **自己** 建 `RobokitClient` 打 TCP，**绕过** `agv_bridge_node`。
- 因此：Mock/真车 Demo 验的是 **Dashboard↔Robokit**，不是 ROS `agv_bridge_node`↔Robokit（后者代码存在，但 soft 路径未默认启用）。

## 3. 已冻结 / 已实现（相对确定）

### 3.1 相机契约 5 问（鹏飞已确认）

文件：`note/相机需要确定的事情/00_鹏飞确认结论.md`

1. Topic **一律绝对名**（带 `/`），如 `/camera/cam_front/info`
2. 权威 `/camera/cam_front/info` **仅 NUC**；Xavier 可选 `/camera/cam_front/driver_info`
3. `transport` 用 `xavier_ros2` / `xavier_ros2_waiting`（禁止裸 `"ros2"`）
4. 图像无 ROS2 `seq`；序号只在 heartbeat；第一版不改 msg
5. Basler IP / 网口名以现场实测为准，勿盲改启动参数

正式通路：Xavier 发 `compressed` + `heartbeat` + `status`；NUC `camera_ingress` 解码 + 看门狗。  
HTTP `:8080` MJPEG 仅为 legacy。

### 4.4 架构/产品风险（主观，求证伪）

1. **双入口控车**：Roboshop 与 Dashboard 都可抢 `4005` 锁 → 现场操作规程是否写清？  
2. **Demo 绕过 `agv_bridge_node`**：两套实现（dashboard 直连 vs bridge node）长期是否分叉？  
3. **同事讲 Nav2、车用 Robokit**：新人/外包是否会按 Nav2 去对接？  
4. **相机与 AGV 不在同一依赖链**：Web「看起来通了」可能只通了一半（有图无车 / 有车无图）。  
5. **Mock 冒烟 ≠ 业务冒烟**：Mock 未验证与真实 smap 站点名、真实激光畸变、真实锁被占用、急停/阻挡字段。  
6. **`devices.yaml` 的 `env.mode` 似乎不直接驱动运行时**；真正切换靠 `/api/env` → `env.json` —— 配置文件可能误导部署。  
7. **电池/阻挡/急停**：`AgvStatus` 有字段，但 bridge 侧未必从 1006/1012 等拉满；Dashboard 仅补了 1007。  
8. **Face 与 cam_front 同提 Xavier `.225`**：硬件/进程边界是否清晰，避免抢相机。  
9. **生产模式 `prod` 明确未启用**；Demo 与生产边界是否被业务方理解。  
10. **本 Agent 环境网络/Docker 异常**：部分「调通」结论依赖 Mock 与文档，**不能等同于现场 NUC 上容器已绿**。
