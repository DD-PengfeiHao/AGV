## 2. 后端必做（优先级 P0）

### 2.1 `dashboard_node.py`

1. 订阅：
   - `/face/status`（`std_msgs/String` JSON）
   - `/face/cam_front/detections`（主；可扩 cam_left/right）
2. 服务客户端：
   - `/face/identify_face` → 暴露 `POST /api/face/identify`
   - （可选）`/face/detect_face`
3. `GET /api/state` **必须含键**（缺键=对齐失败）：
   - `face`：严格按 **docs/19 §4.2**（`peer` 默认写 `192.168.0.225`）
   - `cameras_meta`：严格按 **docs/20 §4.4**
   - `cargo`: `null`（占位）
4. 独立：
   - `GET /api/face/status` → 同 `state.face`
   - `GET /api/face/logs` 或扩展 `/api/logs`（带 `level/event/trace_id/kind=face`）
5. `/api/version` 或 health 注明含 face HTTP：`web_face_api=1`

### 2.2 字段红线

- 路径/字段名 **禁止私改**；要改先 bump `docs/19` 的 `contract_version`
- `camera_name` 枚举仅：`cam_front` | `cam_left` | `cam_right`
- 人脸默认 `cam_front`（相机2）
- **禁止**「识别成功才允许导航」

## 5. 与「重构前端 Agent」边界

| 你做 | 不做 |
|------|------|
| API + 临时可见 UI | 整站大疆风重构、换框架、换端口 |
| 保持相对路径 `/api/*` | 改 docs/19 字段而不通知 |
| 文件仍在 `www/` `www/debug/` | 另起 Vite 开发端口给验收用（可本地开发，产物必须落回 `www/`） |

重构 Agent 会整页替换；你的临时 UI **允许被覆盖**，但你留下的 **API 契约必须留下**。
