---

## 1. info Topic 是否带 `/`

**结论：一律绝对名，带 `/`。**

| 名称 | 最终 Topic |
|------|------------|
| info（NUC 权威） | `/camera/cam_front/info` |
| driver_info（Xavier 可选） | `/camera/cam_front/driver_info` |
| compressed | `/camera/cam_front/image_raw/compressed` |
| heartbeat | `/camera/cam_front/heartbeat` |
| status | `/camera/cam_front/status` |
| capture 服务 | `/camera/capture` |

禁止再写相对名 `camera/cam_front/info`（易进命名空间出错）。

---

## 2. info 两个发布者

**结论：选 B（分 Topic）+ 实际执行上 Xavier 可不发 driver_info。**

| 发布方 | Topic | 含义 |
|--------|-------|------|
| **仅 NUC** `camera_ingress` | `/camera/cam_front/info` | **唯一权威** `connected`（含看门狗） |
| Xavier（可选） | `/camera/cam_front/driver_info` | 驱动侧自检；**业务/Web 不订此 topic** |
| Xavier（必须） | heartbeat + status | `link_ok` / 错误详情 |

`CameraInfoLite` **不加** `source` 字段（第一版不改消息）。  
骨架 `cam_front_ros_node`：**改为发 `/camera/cam_front/driver_info`，不再发 `/camera/cam_front/info`。**

---

## 3. transport 字段不一致

**结论：统一枚举如下（Status JSON 与 CameraInfoLite 相同语义）。**

| 值 | 谁填 | 含义 |
|----|------|------|
| `xavier_ros2` | NUC info（通）/ Xavier status | ROS2 通路正常 |
| `xavier_ros2_waiting` | NUC info | 心跳超时或无帧 |
| `gazebo` | 仿真 | left/right 或未切 ros2 |
| `xavier_mjpeg` | legacy | 仅排障 HTTP 桥 |

**禁止** Status 里再写裸字符串 `"transport":"ros2"`。应写 `"transport":"xavier_ros2"`。

---

## 4. 图像消息没有 seq

**结论：第一版不改消息。**

- ROS2 `std_msgs/Header` **无** `seq`（与 ROS1 不同）。
- `CompressedImage` 只有 `header.stamp` + `header.frame_id`。
- **帧序号只在** `/camera/cam_front/heartbeat` 的 `seq`。
- 图与心跳对齐：用时间接近（`stamp`）即可；需要强关联时第二版再议（例如自定义 ImageMeta），**现在禁止改 msg**。

---

## 5. 相机 IP 与现场不一致

**结论：契约写「推荐拓扑」，启动参数以现场实测为准，禁止未确认就改死。**

| 角色 | 推荐（迁移后） | 历史/未迁移 |
|------|----------------|------------|
| Xavier WiFi（DDS/SSH） | `192.168.0.225` | 同左 |
| NUC | `192.168.0.173` | 同左 |
| Xavier 相机口 | `192.168.1.1/24`（常见名 `eth1`，**以 `ip -br link` 为准**） | 可能无 IP / NO-CARRIER |
| Basler | `192.168.1.100` | 历史日志常见 `192.168.0.100` |

启动参数：

```bash
# 先在 Xavier 确认：
#   ethtool <口> → Link detected: yes
#   ping <实际 Basler IP>
ros2 run camera_bridge cam_front_ros_node --ros-args -p camera_id:=<实测IP>
```

默认骨架仍可用 `192.168.1.100` 作占位，**同事必须以实测 IP 覆盖**。
