# 25 相机 ROS2 工业级通信契约（正式通路）

> 版本：v0.2.1 · 2026-08-07  
> 正式通信：**仅 ROS2**（禁止把 HTTP `:8080` 当生产依赖）  
> Domain：`ROS_DOMAIN_ID=30` · 相机逻辑名：`cam_front`（相机2 / Basler）

**请把本文 + §9 复制页转发给相机同事。**

---

## 1. 目标

1. Xavier（Basler + Aravis）与 NUC 在同一 ROS2 Domain 发现并通信。  
2. NUC 收到压缩图 + 心跳 + 状态；超时能降级告警。  
3. 消息带 `seq` / `stamp` / `frame_id`，心跳 RELIABLE，图像 BEST_EFFORT。  
4. 人脸结果仍按 docs/18；与图像解耦。

## 2. 架构

```text
Basler --Aravis--> cam_front_ros_node (Xavier Humble)
                      |  compressed / heartbeat / status / info
                      |  service /camera/capture
                      v
               camera_ingress_node (NUC)
                      |  decode -> /camera/cam_front/image_raw
                      |  watchdog -> /camera/cam_front/info
                      v
               dashboard_node / face_bridge
```

Xavier：**Humble Docker**（与 NUC 一致）。Ubuntu 20.04 原生 Foxy 不作为首选。

> 5 个契约冲突的确认结论见：`note/相机需要确定的事情/00_鹏飞确认结论.md`。

## 3. Topic / Service / QoS（冻结）

| 名称 | 类型 | QoS | 发布 | 订阅 |
|------|------|-----|------|------|
| `/camera/cam_front/image_raw/compressed` | `sensor_msgs/CompressedImage` jpeg | BEST_EFFORT KEEP_LAST 5 | Xavier | NUC ingress |
| `/camera/cam_front/image_raw` | `sensor_msgs/Image` | 由 NUC 解码后发 | NUC ingress | Web/face |
| `/camera/cam_front/info` | `delivery_interfaces/CameraInfoLite` | RELIABLE KEEP_LAST 1 | **仅 NUC**（看门狗权威） | Web |
| `/camera/cam_front/driver_info` | 同上 | RELIABLE KEEP_LAST 1 | Xavier 可选 | 调试，业务不订 |
| `/camera/cam_front/heartbeat` | `delivery_interfaces/CameraHeartbeat` | RELIABLE KEEP_LAST 1 ≥2Hz | Xavier | NUC |
| `/camera/cam_front/status` | `std_msgs/String` JSON | RELIABLE KEEP_LAST 1 | Xavier | NUC |
| `/camera/capture` | `delivery_interfaces/CameraCapture` | RELIABLE | Xavier | NUC |

> **Topic 一律绝对名（带 `/`）。** 权威 `connected` 只看 `/camera/cam_front/info`（NUC）。  
> 图像无 ROS2 `seq`；序号只在 heartbeat。Status/`info` 的 transport 用 `xavier_ros2` / `xavier_ros2_waiting`（禁止裸 `"ros2"`）。  
> 详见 `note/相机需要确定的事情/00_鹏飞确认结论.md`。

### CameraHeartbeat

`header, camera_name, seq, uptime_sec, fps_actual, frames_total, frames_dropped, link_ok, device_id, error_code, error_msg`

### Status JSON 最低字段

```json
{
  "ok": true,
  "camera_name": "cam_front",
  "transport": "xavier_ros2",
  "peer": "xavier",
  "domain_id": 30,
  "width": 640,
  "height": 480,
  "fps": 10.0,
  "link_ok": true,
  "last_error": "",
  "seq": 1234,
  "device_id": "192.168.1.100"
}
```

### 图像约定

- `frame_id=cam_front_optical`
- `CompressedImage.format=jpeg`
- 联调 640×480 @ 5–10 FPS；稳定后可提高
- `transport` 取值：`xavier_ros2` / `xavier_ros2_waiting` / `gazebo` / `xavier_mjpeg`(legacy)

## 4. 系统侧（NUC / 本仓库）职责

| 项 | 说明 |
|----|------|
| 消息 | `delivery_interfaces` 含 `CameraHeartbeat` |
| 节点 | `camera_bridge/camera_ingress_node` |
| Boot | `CAM_FRONT_SOURCE=ros2`（默认）；`xavier`/`mjpeg` 仅 legacy |
| 行为 | 订 compressed+heartbeat+status；解码发 `image_raw`；心跳超时 `connected=false` |
| 文档 | 本文 + note 共享页 |

```bash
export ROS_DOMAIN_ID=30
export ROS_LOCALHOST_ONLY=0
export CAM_FRONT_SOURCE=ros2
ros2 run camera_bridge camera_ingress_node
```

## 5. 相机同事职责

### 5.1 网络（必须）

- Basler 供电；Xavier `eth1`：`Link detected: yes`
- 建议相机网段 `192.168.1.0/24`（Xavier ETH `192.168.1.1`，相机 `192.168.1.100`）
- **ETH 不设默认网关**；WiFi `.225` 仅给 DDS/SSH
- 禁止与随身 WiFi 双网关抢 `192.168.0.1`

### 5.2 软件

1. Xavier 启动 **ROS2 Humble 容器**（或与 NUC 同发行版）  
2. 编译安装本仓库 `delivery_interfaces`  
3. 运行 `cam_front_ros_node`（仓库骨架）或自研节点，**话题名必须一致**  
4. 无相机时：`link_ok=false`，节点**保持运行**并发心跳（禁止假 `connected=true`）

```bash
export ROS_DOMAIN_ID=30
export ROS_LOCALHOST_ONLY=0
ros2 run camera_bridge cam_front_ros_node --ros-args \
  -p camera_id:=192.168.1.100 \
  -p target_fps:=10.0
```

### 5.3 自测验收

```bash
ros2 topic list | grep cam_front
ros2 topic hz /camera/cam_front/image_raw/compressed
ros2 topic echo /camera/cam_front/heartbeat --once
ros2 topic echo /camera/cam_front/status --once
```

NUC 同 Domain 能 `echo` 到 heartbeat 即算接通。通知系统侧后 Web 相机2应出实拍。

### 5.4 明确禁止

- 生产依赖 `http://*:8080/stream`
- 自造话题名（如 `/basler/image`）
- 无链路时 `info.connected=true`
- 心跳 < 2 Hz 或只发图不发心跳

## 6. 与人脸 docs/18

- 人脸：`/face/cam_front/detections`（B1）  
- 可同机两节点；人脸若需图，订 compressed，勿再开 HTTP

## 7. Legacy

`CAM_FRONT_SOURCE=xavier` → 旧 MJPEG 桥 `xavier_cam_front_bridge`（仅排障）。

## 8. 联调顺序

1. Domain 30 互通（`ros2 topic list` 双边可见）  
2. heartbeat  
3. compressed hz  
4. NUC Web snapshot  
5. 拔相机网线 → `link_ok=false` / NUC `connected=false`
